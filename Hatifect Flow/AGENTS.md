# Flowline

Прочитай корневые инструкции и `README.md`, затем owning Core/Persistence/host код и соседние поведенческие тесты. Модель десяти инкрементов — действующая реализация; не заменяй её старой transport/pipe моделью.

Core владеет идентичностью объектов, состояниями операций, очередями, routing и dispatch. Persistence владеет envelope, совместимостью сохранения, recovery и проверкой идентичности сейва. Stardew host владеет игровым lifecycle. Core/Persistence не читают UI, игровые inventory или конкретный сторонний API.

При изменении перехода состояния проверь повторную команду, отказ provider, прерывание/восстановление и изоляцию сессии/сейва. Не теряй и не дублируй операции при retry/reload. Детерминизм и ограничения обходов должны следовать из кода и проверяться конкретными состояниями.

`Hatifect.Flow.UI.Semantic` содержит live ParcelExperience и NetworkExperience над публичными IFlowApplication/IFlowNetworkApplication: immutable snapshots, команды с session/revision и уведомления после commit. Host-operation guard запрещает повторный вход из inventory callbacks до изменения aggregate. Игровой FlowGameSession поддерживает одиночный save, обычные сундуки и поддерживаемые стопки с выбранным количеством; реальные предметы и transport aggregate сохраняются вместе через SMAPI WriteSaveData. Не подключай fake-provider файловую durability к физическим inventories. Historical custody projection не является текущим содержимым сундука; restore не создаёт уже доставленные предметы. Неоднозначная inventory ошибка сохраняет recovery fence, автоматический replay после неё запрещён; ручное согласование допускает только известный receipt. Возврат груза — отдельное действие custody refund с общей границей числа попыток доставки, без обратного сетевого маршрута. Состояние отображения не становится источником истины домена. Новые границы и ограничения подробно описаны в README.

Команда из корня: `./tools/hatifect-test flow`; для host — `./tools/hatifect-check --platform`. Runtime `flow.route.basic` и `flow.save.isolation` относятся к изолированному fake-provider/lifecycle harness и не доказывают готовность реальных перевозок. `flow.chest.roundtrip` проверяет production-сессию, настоящие сундуки и два цикла Saving/Saved/reload только в канонической request-owned копии сейва. Не меняй реальные сейвы пользователя.
