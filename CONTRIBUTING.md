# Contributing

Hatifect is publicly visible source under a restrictive personal-use license;
it is not an open-source project.

Unsolicited code contributions and pull requests are not accepted. Do not fork,
modify, redistribute, or publish Hatifect except for the limited platform rights
provided directly by GitHub and the personal-use permission in [LICENSE](LICENSE).

You may open a regular GitHub issue for a reproducible, non-security bug report
or a feature suggestion. Do not include credentials, private save files,
personal data, proprietary third-party files, or copied source code. Report
security issues privately as described in [SECURITY.md](SECURITY.md).
